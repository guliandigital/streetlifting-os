Все документы в этой папке — это **стартовые шаблоны**, подготовленные для передачи юристу на доработку и финализацию. **Не подписывайте ни один из этих документов без проверки квалифицированным юристом**, специализирующимся на международном праве, защите персональных данных и интеллектуальной собственности.

## Что предстоит сделать юристу

1. **Проверить шаблоны на соответствие законодательству:**
   - Армении (для ООО «Гулян Диджитал» как lex domicilii разработчика)
   - Нидерландов (для EUSF Stichting)
   - РФ (для АНО «Стритлифтинг» и российских федераций-организаторов)
   - ЕС (для GDPR — DPA)

2. **Дополнить недостающими разделами:**
   - Юрисдикция и применимое право для каждой пары сторон
   - Арбитражные оговорки (международный коммерческий арбитраж — ICC, LCIA, или арбитражный центр Армении)
   - Налоговая часть (НДС в РФ, VAT в ЕС, корпоративный налог Армении 5% для IT)
   - Reverse charge mechanism для B2B-услуг между странами
   - Anti-corruption clause
   - Sanctions compliance (РФ-санкции — ограничения для платежей через Stripe из РФ-юрлиц)

3. **Согласовать ставки и проценты:**
   - Шаблоны используют ставки из решения D40.5: 95%/4%/1%
   - Шаблон цен из D40.1: $0.20–0.60 СНГ, $0.40–1.50 international
   - Все суммы в шаблонах — placeholder, юрист уточнит после разговора с финансистом

4. **Проверить совместимость трёх документов:**
   - SaaS license + DPA + revenue share + brand license должны не противоречить друг другу
   - Brand license не должен запрещать использование, на которое разрешает SaaS license
   - Revenue share от лицензионных платежей не должен противоречить brand license

## Кого найти юриста

### Армения (приоритет — ООО «Гулян Диджитал» как главное юр.лицо)
- Юрист по IT-договорам и интеллектуальной собственности в Ереване
- Опыт международных B2B SaaS-договоров
- Желательно знание русского языка (большинство контрагентов будут русскоязычными в первый год)
- Стоимость: ~$1500–3000 за весь пакет (4 договора + правки)

### Нидерланды (для EUSF Stichting — некоммерческой организации)
- Юрист по non-profit governance и спортивному праву
- Опыт работы с международными спортивными федерациями
- Стоимость: ~€2000–5000

### РФ (для АНО «Стритлифтинг» — Роскомнадзор compliance)
- Юрист по ФЗ-152 «О персональных данных»
- Опыт регистрации операторов ПД в Роскомнадзоре
- Стоимость: ~150–300 тыс. рублей за DPA + регистрацию

### Альтернатива — один международный юрист
Если бюджет ограничен: один опытный международный B2B-юрист (например, в DLA Piper Yerevan, или из ереванской фирмы Concern Dialog) сможет покрыть Армению + базовый GDPR. РФ-часть всё равно потребует отдельного российского юриста.

## Список приоритетов

В порядке важности для запуска V2 (через ~6 месяцев после v0.1.0):

1. **SaaS license** — чтобы первая федерация-организатор могла официально использовать программу
2. **Revenue share agreement** — чтобы автоматически распределять доходы 4%/1%
3. **DPA** — для compliance ФЗ-152 (РФ) и GDPR (ЕС). Без него нельзя запускать backend в V2
4. **Brand license** — наименее срочный; пока используем «ISF v5.1 правила» как public reference, не как коммерческий бренд

## Примерный таймлайн

- **Сейчас (v0.1.0)**: шаблоны существуют для первых разговоров с потенциальными организаторами. Не подписываются.
- **+2 месяца**: юрист в Армении проверяет SaaS license + revenue share. Готовы для пилотных контрактов.
- **+4 месяца**: DPA готов через российского юриста. АНО регистрируется в Роскомнадзоре.
- **+6 месяцев (V2 launch)**: все 4 документа подписаны со всеми сторонами. Backend запускается с нормальной правовой базой.
- **+12 месяцев**: пересмотр документов после первого года эксплуатации.

## Что в шаблонах НЕ покрыто

- Партнёрские договоры с конкурирующими федерациями (WSF, НАП, FinalRep) — это V4+ работа, отдельные документы
- Партнёрство с WADA / ITA по антидопингу — V5+
- Договор с Apple Developer и Microsoft Code Signing — стандартные contracts от вендоров
- Лицензия на использование streetlifting.app домена — простая регистрация через домен-регистратора, не нужен формальный договор
- Внутренние документы ООО «Гулян Диджитал» (устав, NDA с разработчиками) — отдельный пакет
