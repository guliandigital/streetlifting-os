# Streetlifting OS — Руководство секретаря соревнования

Аудитория: секретари федераций, проводящих соревнования по правилам ISF v5.1 / WSF / НАП и других федераций стритлифтинга.

Эта инструкция описывает актуальную версию программы. Версионная информация — в [`../../CHANGELOG.md`](../../CHANGELOG.md). Краткая шпаргалка для первого запуска — в [`quick-start-ru.md`](quick-start-ru.md).

---

## Что умеет программа

Полный цикл соревнования закрыт оффлайн на ноутбуке организатора:

- **Настройка турнира** — пресеты ISF v5.1 (19 дисциплин, весовые и возрастные категории, диски), редактирование под нужды конкретного турнира
- **Регистрация атлетов** — ручной ввод, импорт CSV, жеребьёвка с фиксированным seed
- **Взвешивание** — авто-определение весовой и возрастной категорий, перевзвешивание, bulk-подтверждение
- **Флайт-ордер** — печатный стартовый список по флайтам
- **Судейство** — экран судейства с 60-секундным таймером (классика) и 120-секундным (многоповторка), горячие клавиши, голосование 3 из 3, статус по правилу 2 из 3
- **Расчёт результатов** — по категориям (с местами), абсолютка через ISF-коэффициент, командный зачёт, **прогноз места и килограммов до первого**, отдельная таблица для многоповторки
- **Records-экран** — рекорды соревнования по дисциплина × возраст × весовая × упражнение
- **Scoreboard** — публичный экран для проектора / TV: текущий атлет, попытки, таймер
- **Print forms** — печатные формы: протокол, карточки регистрации, грамоты
- **Выгрузка протоколов** — CSV (UTF-8 BOM, совместим с Excel и PowerTable)
- **Сохранение / загрузка** — `.json`-файлы, версионированный формат с миграциями
- **Двуязычный интерфейс** — русский / английский, переключается одной кнопкой

Программа работает полностью **оффлайн**. Никаких блокирующих обращений в интернет на турнире.

## Чего пока нет (на радаре V1.x → V2)

- **Code-signing** (Windows EV + Apple Developer ID) — релизы пока не подписаны, при установке появятся предупреждения SmartScreen / Gatekeeper
- **Auto-updater** — инфраструктура готова, но pubkey-плейсхолдер; будет активирован вместе с code-signing
- **Cross-competition records archive** — рекорды по нескольким турнирам (V2)
- **Бэкенд:** онлайн-регистрация, биллинг, синхронизация — V2
- **UAT на боевом турнире** — проверка под реальной нагрузкой федерации

Для актуального плана работ см. [`../../README.md`](../../README.md) § Roadmap.

## 1. Установка программы

### Windows
Скачайте `StreetliftingOS_*_x64-setup.exe` со [страницы релизов](https://github.com/GulianDigital/streetlifting-os/releases/latest). Запустите. SmartScreen покажет «Защитник Windows предотвратил запуск неизвестного приложения» — нажмите **«Подробнее»** → **«Выполнить в любом случае»**. Установка идёт в `%LOCALAPPDATA%`, права администратора не нужны.

### macOS
Скачайте `.dmg` (universal — для Intel и Apple Silicon). Откройте, перетащите Streetlifting OS в «Программы». При первом запуске Gatekeeper откажет — закройте окно, найдите программу в «Программах», правый клик → **«Открыть»** → подтвердить. Дальше будет открываться обычным двойным кликом.

### Linux
- **AppImage** — `chmod +x StreetliftingOS_*.AppImage` → двойной клик
- **DEB** (Debian / Ubuntu) — `sudo dpkg -i StreetliftingOS_*.deb`
- Зависимости: `libwebkit2gtk-4.1-0`, `libgtk-3-0`, `libayatana-appindicator3-1`

### Браузерная версия (PWA)
Если установить нельзя (запрет в корпоративных политиках, рабочий ноутбук) — откройте <https://guliandigital.github.io/streetlifting-os-legacy/> в Edge / Chrome / Firefox. Сохраняйте на флэшку или в облако вручную через кнопку «Сохранить».

Подробности по установке для каждой ОС — в [`../installation-v1.md`](../installation-v1.md).

## 2. Подготовка к турниру

### 2.1. Создать соревнование

Главная страница → **«Новое соревнование»**. Загрузятся ISF v5.1 пресеты.

### 2.2. Настройка соревнования

Боковое меню → **«Настройка»**. Пять вкладок:

**Основные:**
- Название турнира
- Федерация (свободный текст)
- Страна, регион, город
- Дата
- Формат: Classic / Multirep / Weighted Calisthenics
- Формула очков (для абсолютки)
- Переключатели:
  - **Masters-коэффициент** — применять M1–M6 множители
  - **Lower-BW-first tiebreak** — при равных результатах выше место у атлета с меньшим весом тела (ISF §7.10)

**Дисциплины** — 19 ISF-дисциплин разделены на Classic (PU + DI + PUDI варианты) и Multirep. Кнопки «Выбрать все Classic / Multirep». На турнире будут видны только включённые здесь дисциплины.

**Весовые категории** — два столбца: мужские / женские. Включаемые категории галочкой. «Сбросить к ISF-дефолтам» возвращает стандартный набор.

**Возрастные категории** — Open / Youth / Junior / Masters M1 (35–39) / M2 (40–49) / M3 (50–59) / M4 (60+) / **M5 (60–69, ×1.125)** / **M6 (70+, ×1.150)**. Последний разделяется на 69 и 70 годах — критично для корректного применения коэффициентов по ISF v5.1 §10.9.4.

**Диски** — таблица: вес (кг), пар, цвет (для UI), флаг «только для рекордных подходов» (если этот диск нельзя использовать в обычных попытках). Можно добавлять / удалять / редактировать inline.

### 2.3. Регистрация атлетов

Боковое меню → **«Регистрация»**.

**Способ 1 — ручной ввод:** «Добавить спортсмена», заполнить форму (валидация zod):
- ФИО, пол (M / F), дата рождения (YYYY-MM-DD), страна
- Дивизион: Любители / Профи / Гость (Guest — без зачёта в общем рейтинге)
- Дисциплина: одна из включённых на этапе настройки
- Опционально: команда, ID атлета, Instagram, заметки, день / помост / флайт

**Способ 2 — импорт CSV:** «Импорт CSV» → выбор файла. Обязательные колонки: `name, sex, division, disciplineCode`. Опциональные:
```
birthDate (YYYY-MM-DD), country, day, platform, flight, team, memberId,
guest (true/false/1/0), instagram, notes, bodyweightKg, reweighKg
```

Форматы:
- Кодировка: UTF-8 (с BOM или без)
- Заголовки: case-insensitive, понимаются snake_case (`Bodyweight_Kg` → `bodyweightKg`)
- Десятичный разделитель: только точка (`75.5`, не `75,5`)
- Булевы значения: `1/0/true/false/yes/no`

При импорте программа покажет превью с ошибками построчно — атлеты с ошибками не будут добавлены, остальные пройдут.

**Способ 3 — экспорт + редактирование + импорт.** Сначала «Экспорт CSV» (получите шаблон с правильными колонками) → правьте в Excel → импорт назад.

### 2.4. Жеребьёвка

После регистрации — **«Жеребьёвка»**. Программа использует Fisher-Yates на seeded mulberry32 PRNG для воспроизводимости. Введите seed (любое число) — при повторе с тем же seed получите тот же порядок. Это полезно если нужно подтвердить результат жеребьёвки спустя время.

Жеребьёвка задаёт `entryIndex` для каждого атлета — порядок выхода для многоповторки и tiebreak в классике.

## 3. День турнира

### 3.1. Взвешивание

Боковое меню → **«Взвешивание»**.

Двойной клик в столбец «Вес (кг)» → введите вес с шагом 0.1 кг → Enter. Программа сразу автоматически определит:
- **Весовую категорию** по правилу `minKg < bw ≤ maxKg` (ISF §7.2 — нижняя граница строгая)
- **Возрастную категорию** на дату турнира

Если атлет хочет перевзвеситься (например, скинул 200 г после взвешивания) — заполните столбец «Перевзвешивание». Программа будет использовать `reweighKg`, если он задан, иначе `bodyweightKg`.

Особый случай — категория **M_52** (мужская до 52 кг). По решению ISF (D28) она открыта только для **юношей и юниоров**, не для Open / Senior. Программа автоматически не назначит её взрослому атлету.

После всех взвешиваний — **«Подтвердить всех»**. Лист закроется, дальше идут флайт-ордер и судейство.

### 3.2. Флайт-ордер

Боковое меню → **«Флайт-ордер»**. Стартовый список выводится:
- Сгруппирован по флайтам
- Сортировка: по заявленному весу первой попытки ASC (для классики) / по `entryIndex` ASC (для многоповторки)
- Фильтр упражнения (PU / DI / All)

Кнопка **«Печать»** вызывает `window.print()` со стилями `@media print` — в PDF не попадает интерфейс программы, только сам список.

### 3.3. Судейство

Боковое меню → **«Судейство»**. Откроется панель с:

**Вкладки сверху** — по одной на каждую включённую дисциплину. Активируется первая доступная.

**Левая панель — очередь:** следующие 5 атлетов в порядке round-system (ISF §7.4.3). Сортировка: заявленный вес ASC → вес тела ASC (если включён `lowerBodyweightFirstTiebreak`) → `entryIndex` ASC. Когда все три попытки одного раунда сделаны, очередь автоматически переходит к следующему раунду.

**Правая панель — активный атлет:**
- ФИО, категория, вес тела
- Текущий раунд (1 / 2 / 3)
- Заявленный вес попытки

**Таймер** — 60 секунд для классики, 120 для многоповторки. Большой циферблат + цветной кольцевой индикатор:
- Зелёный: > 20 с
- Оранжевый: 10–20 с
- Красный: < 10 с

Звуковой сигнал на 0 секунд (Web Audio API). Кнопки **«Старт» / «Стоп»**.

**Три карточки судей** — Левый / Центральный / Правый. На каждой:
- Зелёная кнопка ✓ (зачёт / Good Lift)
- Красная кнопка ✗ (не зачёт / No Lift)
- Ссылка «Сбросить» если ошибочно нажали

**Live-статус:** PENDING / GOOD LIFT / NO LIFT, считается на лету по правилу 2-из-3. Если решение спорное (2:1) — рядом появится бейдж «2-1».

**Горячие клавиши** (фокус не должен быть в инпуте):

| Клавиша | Действие |
|---|---|
| `Q` / `A` | Левый судья: зачёт / не зачёт |
| `W` / `S` | Центральный судья |
| `E` / `D` | Правый судья |
| `Space` | Подтвердить попытку (когда все три голоса выставлены) |
| `Esc` | Сбросить все голоса |

**Кнопки «Зачёт всем» / «Не зачёт всем»** — для случая когда судейство ведёт один человек (соло-сценарий, тренировочные турниры).

**«Подтвердить попытку»** — записывает голоса в `entry.exercises[exercise].attempts[seq]`, переходит к следующему атлету в очереди.

**«Пропуск / Не явился»** — переход к следующему без записи попыток (атлет отсутствует).

**Многоповторка:** дополнительно есть `NumberInput` для числа повторений. Программа сама подставляет `presetLoadKg` из ISF-каталога. PUDI-дисциплины (подтягивания + отжимания вместе) дают **два пункта в очереди** на одного атлета — отдельно PU, отдельно DI.

### 3.4. Результаты

Боковое меню → **«Результаты»**.

**Вкладка «По категориям»** — Classic-результаты, сгруппированные по `(пол × возрастная категория × весовая категория)`. В каждой группе таблица:
- ФИО
- Попытки PU 1 / 2 / 3 (зелёный фон = зачёт, красный + зачёркнутое = не зачёт)
- Попытки DI 1 / 2 / 3
- Лучший PU, лучший DI, сумма
- ISF-очки
- Место (золото / серебро / бронза = золотистый / серебряный / бронзовый фон)
- Гости — курсивом, без места

Тибрейк по ISF §7.10: при равной сумме — выше место у атлета с меньшим весом тела.

**Вкладка «По ISF-очкам»** — плоский ранкинг по абсолютному коэффициенту, считается через формулу:
```
Coefficient = 100 / (A − B × e^(−C × bodyweight_kg))
```
с шестью наборами констант (M / F × PU / DI / PUDI), импортированными из streetlifting.ru/points/. Гости не учитываются.

**Вкладка «Многоповторный»** — multirep-результаты, сгруппированные так же. Колонки: PU repetitions, DI repetitions, total reps, preset load, ISF points. Сортировка: total reps DESC → bodyweight ASC → entryIndex ASC.

**Колонки прогноза** в абсолютной вкладке: «Прогн. место» (текущая позиция в категории) и «Кг до 1-го» (минимальный вес для опережения лидера + 1.25 кг шаг). Считаются на лету, не сохраняются.

**Командный зачёт (team scoring)** — отдельная сводка в Results. Сумма очков по командам с настраиваемым правилом «брать топ-N от команды». Используется на турнирах с командным первенством.

**Кнопка «Скачать CSV»** — экспорт Classic + Multirep в одном файле. UTF-8 BOM, формат колонок совместим с PowerTable (по findings v2 §4.3).

### 3.5. Records — рекорды соревнования

Боковое меню → **«🏅 Рекорды»** (роут `/records`).

Показывает рекорды, установленные в рамках текущего соревнования, сгруппированные по `(дисциплина → пол → возрастная категория → весовая категория × упражнение)`:

- **Classic-рекорды**: лучший PU кг, лучший DI кг, лучшая сумма
- **Multirep-рекорды**: максимум повторений PU, DI, общий

Если в группе нет атлетов или все попытки нулевые — категория не отображается (empty state). Гости учитываются (можно показать рекорд гостя).

Кнопка **«Печать»** — печать через `window.print()`.

Cross-competition records archive (история рекордов между турнирами) пока **не реализован** — это V2 задача.

### 3.6. Scoreboard — публичный экран

Боковое меню → **«📺 Табло»** (роут `/scoreboard`).

Этот экран рассчитан на проектор / TV в зале для зрителей и атлетов. Открывайте его в отдельном окне браузера (или на втором мониторе) и растяните на проекционный экран.

Показывает в крупном масштабе:
- Текущий атлет на помосте
- Заявленный вес попытки
- Таймер (синхронизирован со screen судейства)
- Очередь следующих

В отличие от остальных экранов, scoreboard **не требует RequireMeet-guard** — он берёт состояние из общего стора и работает в read-only режиме. Это позволяет безопасно отдать второй компьютер с этим URL комментатору.

### 3.7. Print — печатные формы

Боковое меню → **«🖨️ Печать»** (роут `/print`).

Объединяет печатные формы:
- **Протокол соревнования** — итоговая форма с местами, попытками, очками
- **Карточки регистрации атлетов** — для подачи на помост
- **Грамоты** — по категориям, абсолютному первенству, командному зачёту

Печать через системный диалог (`window.print()`), стили `@media print` скрывают навигацию. Можно сохранить в PDF через системный «Print to PDF».

## 4. Сохранение и резервные копии

### Файл соревнования

Главная страница → **«Сохранить»**. Откроется системный диалог выбора места — рекомендую сохранять в:
1. На локальный диск (рабочий стол / папка организатора)
2. На флэшку (резерв)
3. В облако (резерв) — Яндекс.Диск, Google Drive, OneDrive

Имя файла генерируется автоматически: `2026-04-26_Название_соревнования_streetlifting-os.json`.

Формат — обычный JSON с `stateVersion: "2"`. Открыть можно в любом текстовом редакторе для аудита, но изменять руками не рекомендуется (можно сломать инварианты).

### ⚠️ Резервные копии — обязательно

Программа полностью оффлайн. Если ноутбук упадёт / батарея сядет / система зависнет в перерыве между потоками — данные сохранятся только на этом ноутбуке. **Сделайте резервную копию на флэшку перед стартом** и периодически жмите «Сохранить» в перерывах между потоками.

В будущей версии будет автосохранение каждые N минут — пока что ответственность на организаторе.

### Загрузка после перерыва

Главная страница → **«Загрузить»** → выберите `.json`-файл. Программа применит миграцию `v1 → v2` если файл из старой версии. Все данные восстановятся, в т.ч. позиция в очереди судейства.

## 5. Что НЕ персистится сознательно

- **Состояние таймера** — таймер обнуляется при перезагрузке (D-решение: операторам нужно явно перезапустить отсчёт после восстановления, а не получить «таймер уже идёт» с непонятно какого момента)
- **Pending votes** — голоса до подтверждения попытки. Если перезагрузились мид-попытки — голоса сбрасываются, нужно проголосовать заново.
- **Активный атлет** — позиция в очереди сохраняется, но «текущий атлет на помосте» вычисляется заново при загрузке.

Это не баг — это инвариант: всё, что может быть посчитано, считается, не хранится.

## 6. Контрольные значения корректности

Если хотите быстро проверить, что программа считает правильно:

**Тест M5/M6:**
- Атлет 69 лет, 80 кг, M, сумма PU 100 + DI 100 = 200 → коэффициент Masters ×1.125 (M5)
- Атлет 70 лет, 80 кг, M, сумма та же → коэффициент **×1.150** (M6)
- Если программа вам показывает 1.125 на 70 годах — она неправильно реализует ISF v5.1 §10.9.4. Streetlifting OS — правильно.

**Тест весовой категории (открытая нижняя граница):**
- Атлет 75.0 кг → категория `-75` (т.к. 75.0 ≤ 75.0)
- Атлет 75.1 кг → следующая категория (т.к. 75.1 > 75.0)
- Это правило `minKg < bw ≤ maxKg` по ISF §7.2.

**Тест M_52 youth-only:**
- Атлет 19 лет, 50 кг, M, дивизион Open → программа НЕ назначит M_52, перейдёт к ближайшей доступной (-56)
- Атлет 17 лет, 50 кг, M, дивизион Юноши → M_52 будет назначен корректно
