# Streetlifting OS — Быстрый старт за 5 минут

Это короткая шпаргалка для первого запуска. Полное руководство — в файле [`operator-manual-v0.1.0-ru.md`](operator-manual-v0.1.0-ru.md).

## 1. Установить (1 минута)

- **Windows**: скачайте `StreetliftingOS_0.1.0_x64-setup.exe` → запустите → если появится предупреждение SmartScreen, нажмите «Подробнее → Выполнить в любом случае»
- **macOS**: скачайте `.dmg` → перетащите в «Программы» → правый клик → «Открыть»
- **Linux**: скачайте `.AppImage` → `chmod +x` → двойной клик
- **Без установки**: откройте [https://streetlifting.app](https://streetlifting.app) в Edge / Chrome / Firefox (Яндекс.Браузер не подойдёт)

## 2. Создать соревнование (30 секунд)

Запустите программу → нажмите **«Новое соревнование»**. Готово — все правила ISF v5.1 уже загружены.

## 3. Зарегистрировать спортсменов (2 минуты)

В верхнем меню — **«Регистрация»**.

**Вариант А — вручную:**
Нажмите **«Добавить спортсмена»**. Заполните форму:
- ФИО, пол, дата рождения, страна
- Дивизион: Любители / Профи
- Дисциплина: выбрать из списка (например, «Классический стритлифтинг (двоеборье)»)

Нажмите **«Сохранить»**. Повторите для каждого спортсмена.

**Вариант Б — импорт из Excel:**
Подготовьте CSV-файл с колонками `name, sex, division, disciplineCode, birthDate`. Сохраните в кодировке UTF-8 (Excel: «Сохранить как → CSV UTF-8»). Нажмите **«Импорт CSV»** → выберите файл → подтвердите.

## 4. Провести взвешивание (1 минута на спортсмена)

В верхнем меню — **«Взвешивание»**.

Двойной клик в колонку **«Вес (кг)»** → введите вес с точностью 0.1 кг → Enter.

Программа сама определит:
- **Весовую категорию** (из 7 женских / 12 мужских)
- **Возрастную категорию** (Open / Юноши / Юниоры / Masters M1–M6)

После всех взвешиваний — кнопка **«Подтвердить всех»**.

## 5. Сохранить файл (10 секунд)

Главная страница → **«Сохранить»** → выберите место сохранения (флэшка / облако / рабочий стол).

Имя файла генерируется само: `2026-04-26_Название_соревнования_streetlifting-os.json`.

⚠️ **Делайте резервную копию на флэшку и в облако** перед турниром — на всякий случай.

---

## Что эта версия пока **не умеет**

В версии 0.1.0 есть подготовка к турниру (регистрация + взвешивание), но **нет экрана судейства с таймером**. Само судейство в этой версии ведётся параллельно в любом удобном инструменте (бумажный протокол).

Полный функционал (судейство, расчёт результатов, дипломы) появится в версии 0.2.0 через 2–3 месяца.

---

## Самая частая проблема

**«Программа не запускается»** — причина почти всегда в антивирусе или в SmartScreen. Решение: добавьте `Streetlifting OS` в исключения антивируса; либо при первом запуске нажмите «Подробнее → Выполнить в любом случае».

Это происходит потому, что у нас пока нет коммерческого сертификата подписи разработчика ($300/год). На версии 1.0+ сертификат появится и предупреждения исчезнут.
