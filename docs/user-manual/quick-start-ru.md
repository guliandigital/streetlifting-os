# Streetlifting OS — Быстрый старт за 5 минут

Шпаргалка для первого запуска. Полное руководство — в [`operator-manual-ru.md`](operator-manual-ru.md).

Эта инструкция написана для актуальной версии Streetlifting OS — поддерживается весь цикл соревнования: настройка, регистрация, взвешивание, флайт-ордер, судейство, результаты.

## 1. Установить (1 минута)

- **Windows**: скачайте `StreetliftingOS_*_x64-setup.exe` с [страницы релизов](https://github.com/GulianDigital/streetlifting-os/releases/latest) → запустите → если появится предупреждение SmartScreen, нажмите «Подробнее → Выполнить в любом случае»
- **macOS**: скачайте `.dmg` → перетащите в «Программы» → правый клик → «Открыть»
- **Linux**: скачайте `.AppImage` → `chmod +x` → двойной клик
- **Без установки**: откройте <https://guliandigital.github.io/streetlifting-os-legacy/> в Edge / Chrome / Firefox (Яндекс.Браузер не подойдёт). Программа работает оффлайн после первого открытия.

Лицензионная программа пока не подписана — предупреждения SmartScreen / Gatekeeper при первом запуске нормальны. Подробности по обходу — в [`installation-v1.md`](../installation-v1.md).

## 2. Создать соревнование (30 секунд)

Запустите программу → нажмите **«Новое соревнование»**. Загрузятся пресеты ISF v5.1: дисциплины, весовые / возрастные категории, диски.

Если нужно подправить — откройте **«Настройка»** в боковом меню. Пять вкладок:
- **Основные** — название, федерация, страна, регион, город, дата, формат, формула очков
- **Дисциплины** — 19 ISF-дисциплин в две группы (Classic + Multirep)
- **Весовые категории** — мужские / женские, можно сбросить к ISF-дефолтам
- **Возрастные категории** — Open / Юноши / Юниоры / Masters M1–M6
- **Диски** — вес, количество пар, цвет, флаг «только для рекордов»

## 3. Зарегистрировать спортсменов (2 минуты на 50 человек)

Боковое меню → **«Регистрация»**.

**Вариант А — вручную:** «Добавить спортсмена» → ФИО, пол, ДР, страна, дивизион (Любители / Профи), дисциплина → «Сохранить».

**Вариант Б — импорт CSV:** «Импорт CSV» → выберите файл. Минимальный набор колонок: `name, sex, division, disciplineCode`. Опционально: `birthDate, country, day, platform, flight, team, memberId, guest, instagram, notes, bodyweightKg, reweighKg`. UTF-8 с BOM — Excel откроет кириллицу корректно.

После регистрации — **«Жеребьёвка»** для получения порядка выходов. Можно зафиксировать seed для воспроизводимости.

## 4. Провести взвешивание (1 минута на спортсмена)

Боковое меню → **«Взвешивание»**.

Двойной клик в колонку «Вес (кг)» → введите вес с точностью 0.1 кг → Enter. Программа сама определит:
- **Весовую категорию** (по правилу `minKg < bw ≤ maxKg`)
- **Возрастную категорию** (Open / Юноши / Юниоры / Masters M1–M6 — с правильным разделением M5/M6 на 70 годах)

Если атлет хочет перевзвеситься — введите новое значение в колонку «Перевзвешивание». Программа учтёт реальный вес автоматически.

После всех взвешиваний — **«Подтвердить всех»**.

## 5. Стартовый список (1 минута)

Боковое меню → **«Флайт-ордер»**.

Список выводится по флайтам, отсортирован по заявленному весу (для классики) или порядку жеребьёвки (для многоповторки). Кнопка «Печать» отдаёт чистый PDF без интерфейса.

## 6. Провести соревнование

Боковое меню → **«Судейство»**.

Вкладки переключают дисциплины. Слева — очередь следующих 5 атлетов. Справа — текущий атлет, его попытка, заявленный вес, таймер.

**Горячие клавиши** (работают, если фокус не в форме ввода):

| Клавиша | Действие |
|---|---|
| `Q` / `A` | Левый судья: зачёт / не зачёт |
| `W` / `S` | Центральный судья |
| `E` / `D` | Правый судья |
| `Space` | Подтвердить попытку (когда все три голоса выставлены) |
| `Esc` | Сбросить все голоса |

Таймер: 60 секунд для классики, 120 секунд для многоповторки. Звуковой сигнал на нуле.

После трёх голосов программа сама посчитает результат по правилу 2-из-3.

## 7. Сохранить файл (10 секунд)

Главная страница → **«Сохранить»** → выберите место сохранения (флэшка / облако / рабочий стол). Имя файла: `2026-04-26_Название_соревнования_streetlifting-os.json`.

⚠️ **Делайте резервную копию на флэшку и в облако** перед турниром — на случай если ноутбук упадёт в перерыве. Программа полностью оффлайн, поэтому ответственность за бэкап на организаторе.

## 8. Результаты и протокол

Боковое меню → **«Результаты»**.

Три вкладки:
- **По категориям** — таблицы с попытками, цветовые статусы, места в категориях
- **По ISF-очкам** — абсолютка по коэффициенту + колонки прогноза («Прогн. место», «Кг до 1-го»)
- **Многоповторный** — отдельная таблица для multirep-дисциплин

Плюс блок командного зачёта (team scoring) если в турнире участвуют команды.

«Скачать CSV» — выгружает Classic + Multirep в одном файле, формат совместим с PowerTable. Открывается в Excel сразу с правильной кодировкой.

## 9. Дополнительные экраны

После того как турнир идёт, доступны:

- **«🏅 Рекорды»** (`/records`) — рекорды соревнования по дисциплина × возраст × вес × упражнение. Кнопка печати.
- **«📺 Табло»** (`/scoreboard`) — публичный экран для проектора / TV. Открывайте в отдельном окне браузера на проекторе. Текущий атлет, попытка, таймер крупным.
- **«🖨️ Печать»** (`/print`) — печатные формы: протокол, карточки регистрации, грамоты. Через системный диалог печати, можно «Save to PDF».
