## 1. Имя продукта

**Полное имя:** Streetlifting OS
**Сокращение:** SL OS (только во вторичных контекстах — внутренние документы, иконки)
**Произношение:** «Стритлифтинг О-Эс» (русский) / «Streetlifting O-S» (английский)
**Не использовать:** «SLOS», «Streetlift OS», «Стритлифтинг ОС» (без дефиса), «StreetLifting OS» (camelCase)

### Юридический статус имени
- Имя зарегистрировано как торговая марка ООО «Гулян Диджитал» (Армения) — *в процессе оформления, V2*
- Программа разработана для нужд EUSF Stichting и других федераций стритлифтинга
- Использование имени третьими сторонами требует письменного согласия

### Палитра ISF Red (полная гамма)

Mantine генерирует 10 оттенков от светлого до тёмного для основного цвета. Полная гамма уже зашита в `app/src/app/theme.ts`:

```ts
const isfRed = [
  "#ffe5e8",  // 0 — самый светлый, для фонов
  "#ffb8be",  // 1
  "#ff8a93",  // 2
  "#ff5d68",  // 3
  "#ff2f3e",  // 4
  "#e6151f",  // 5
  "#c8102e",  // 6 — основной (используется по умолчанию)
  "#a50d24",  // 7
  "#7d0a1b",  // 8
  "#560613",  // 9 — самый тёмный
];
```

### Откуда взят ISF Red

`#C8102E` — приближение к красному цвету флагов федераций стритлифтинга. Цвет выбран потому, что:
- Узнаваемо ассоциируется со спортом / силой / ярким соревнованием
- Хорошо читается на белом фоне (контраст 5.7:1, проходит WCAG AA)
- Не совпадает дословно с red'ом IPF / WPC / других конкурирующих федераций — наш оттенок чуть холоднее

⚠️ Если EUSF Stichting предоставит официальные цвета бренда «ISF» (трек B, лицензионный договор) — заменим на них. Текущий `#C8102E` — placeholder.

## 4. Типографика

### Веб-приложение и документация
- **Основной шрифт:** системный sans-serif стек — `system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, sans-serif`
- Это даёт нативный шрифт ОС: Segoe UI на Windows, San Francisco на macOS, Roboto на Linux/Android

**Преимущества:**
- Размер бандла не растёт (никаких веб-шрифтов не загружаем)
- Нативный вид = нативное доверие пользователя
- Идеальная читаемость на всех платформах
- Поддерживает кириллицу, латиницу, греческий, китайский без дополнительных файлов

### Размеры шрифтов
- Заголовок страницы (H1): 32 px / bold
- Заголовок секции (H2): 24 px / bold
- Заголовок карточки (H3): 18 px / semibold
- Основной текст: 14 px / regular
- Подсказки и пометки: 12 px / regular
- Бейджи и теги: 11 px / semibold

### Маркетинговые материалы и логотип
Для логотипа и презентаций — использовать тот же системный стек, **за исключением**:
- Главная страница сайта streetlifting.app может использовать **Inter** или **Manrope** (gostatic-fonts) для более брендированного вида
- Решение откладывается до финального брендинга (трек A v2)

## 5. Голос и тон бренда

### Принципы
1. **Прямой и ясный** — никаких корпоративных эвфемизмов. «Программа» вместо «решение». «Сохранить» вместо «зафиксировать сохранение».
2. **Без англицизмов где возможно** — «соревнование», не «ивент»; «номинация», не «нoмiнейшн»; «взвешивание», не «вейн».
3. **Уважительный к опыту пользователя** — секретарь федерации — это профессионал с многолетним опытом, к нему обращаемся на «вы».
4. **Технически точный** — если правило ISF говорит «1.150 для Masters M6» — пишем «1.150 для Masters M6», без округлений и упрощений.
5. **Открытый о ограничениях** — если фича пока не реализована — пишем «появится в версии 0.2.0», а не «скоро».

### Что говорить и что не говорить

| Хорошо | Плохо |
|---|---|
| «Сохранение работает оффлайн» | «Семлесс синк прямо здесь и сейчас» |
| «В версии 0.1.0 нет экрана судейства» | «Скоро добавим» / «над этим работаем» |
| «Streetlifting OS — программа для проведения соревнований» | «Революционная платформа нового поколения» |
| «Файл повреждён, проверьте источник» | «Упс, что-то пошло не так» |

## 6. Логотип

### Текущее состояние (v0.1.0)
- **Используется placeholder-логотип** — белая надпись «SL OS» на красном квадрате `#C8102E`
- Размеры: 32×32, 128×128, 256×256, 512×512 PNG + .ico (Windows) + .icns (macOS)
- SVG-источник: `docs/brand/logo-placeholder.svg`
- Скрипт генерации: `app/scripts/generate-icons.ts`

### Финальный логотип (v0.2.0+)
**Ещё не разработан.** Требования к финальному варианту:
- Простой и узнаваемый в маленьком размере (16×16 фавикон должен читаться)
- Работает на любом фоне (светлый, тёмный, цветной)
- Не содержит слишком тонких линий (плохо рендерится на низких разрешениях)
- Не зависит от текста (понятен без надписи «Streetlifting OS» рядом)
- Не похож на логотипы IPF, WPC, WSF, IWF (риск trademark-конфликта)
- Передаёт идеи: спорт, сила, точность, технология

Возможные направления:
- Стилизованная фигура атлета на турнике / брусьях (наиболее узнаваемо для streetlifting)
- Геометрическая абстракция (квадрат + диагональ = «штанга на пояс»)
- Монограмма «SL» в спортивном стиле

### Бюджет на финальный логотип
- **Свои силы** (Figma / Canva): $0, ~5–10 часов работы основателя
- **Junior дизайнер на freelance** (Behance, Dribbble): $200–500
- **Senior дизайнер / агентство**: $1000–5000
- **Конкурс на 99designs или подобной платформе**: $300–800

Рекомендация: попробовать своими силами для версии 0.2.0; если результат не нравится — нанять freelance-дизайнера к версии 1.0.0 (production launch).

### Скрипт генерации
Все иконки генерируются из единого SVG-источника `docs/brand/logo-placeholder.svg` через скрипт `app/scripts/generate-icons.ts` (использует библиотеку `sharp`).

Запуск:
```bash
cd app
npm run icons:generate
```

После запуска — закоммитить изменения в `app/src-tauri/icons/` и `app/public/`.

## 8. Применение бренда — Do и Don't

### Do
- Использовать `#C8102E` как главный акцент (кнопки, ссылки, заголовки разделов)
- На красных фонах текст всегда белый
- На белых / светлых фонах — текст `#1A1A1A`
- Одна основная кнопка действия на экран (например, «Сохранить») — она красная; остальные — нейтральные серые
- Пробелы по 4/8/16/24/32 px — кратные 4, для визуальной гармонии
- Скругление углов 4 px (по умолчанию Mantine)

### Don't
- Не использовать радужные градиенты, неон, металлические эффекты
- Не использовать другие красные оттенки рядом с `#C8102E` — будет визуально неприятно
- Не использовать больше двух цветов в одном блоке (плюс серый и белый — допустимо)
- Не делать размер шрифта меньше 11 px
- Не использовать ALL CAPS для длинных предложений
- Не использовать иконки без подписи (для интернационализации — лучше иконка + текст)

## 10. Защита бренда

### Регистрация
- ООО «Гулян Диджитал» (Армения) подаёт на регистрацию торговой марки `Streetlifting OS` в:
  - Роспатент (РФ)
  - EUIPO (ЕС, через Madrid Protocol)
  - USPTO (США, через Madrid Protocol)
- Стоимость: ~$1500–3000 за все три юрисдикции
- Срок: 8–18 месяцев
- Необходимость: до production launch v1.0.0

### Использование третьими сторонами
- Федерации-партнёры (после подписания контракта) могут использовать «Powered by Streetlifting OS» в маркетинге своих соревнований
- Бесплатные блогеры и YouTube-обзорщики могут использовать имя без согласия (free press)
- Конкуренты (PowerTable, PowerGage, Goodlift) НЕ могут использовать имя для своих продуктов
- Доменные имена `streetlifting-os.com`, `streetliftingos.app`, и т.п. — зарегистрировать на ООО «Гулян Диджитал» как defensive registrations

## 11. Брендирование федерации (V3+)

В версии 3 и выше планируется поддержка co-branding с конкретными федерациями:

### Default (без партнёрской федерации)
Главная страница: «Streetlifting OS»

### С ISF (anchor partner)
Главная страница: «Streetlifting OS · Powered by ISF»
Дополнительный логотип ISF в шапке (если EUSF предоставит права)

### С другими федерациями (WSF, НАП, FinalRep — V4+)
Главная страница: «Streetlifting OS · For [Federation Name]»
Двойное брендирование, цвета федерации в качестве вторичного акцента

Технически — реализуется через `federation-pack.json` (см. `architecture-v1.md` § Multi-federation), задаёт логотип, цвета, brand-теги.
