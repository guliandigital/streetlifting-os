Streetlifting OS — logo asset pack

Состав архива:
00_source — исходные изображения, из которых собраны варианты.
01_horizontal — горизонтальные версии: основная и compact.
02_vertical — вертикальные версии.
03_symbol — отдельный символ / знак.
04_wordmark — текстовый блок Street Lifting OS.
05_favicon — favicon PNG разных размеров, favicon.ico, apple-touch-icon, android icons и пример webmanifest.
06_social — иконки для приложения/аватаров и Open Graph баннеры.
07_previews — общий превью-лист набора.

Обозначения файлов:
_light — бело-зелёная версия для тёмного фона.
_dark — графитово-зелёная версия для светлого фона.
_mono-white / _mono-black — одноцветные инверсии.
_transparent — прозрачный фон.
_on_black / _on_white — версии сразу с фоном для быстрого использования.

Рекомендации:
• Для тёмного интерфейса используйте 01_horizontal/horizontal_light_transparent.png.
• Для светлого интерфейса используйте 01_horizontal/horizontal_dark_transparent.png.
• Для компактных блоков используйте horizontal_compact_*.
• Для favicon чаще всего подходит 05_favicon/favicon.ico или android-chrome-192x192.png.
• Для аватаров и соцсетей используйте 06_social.

Важно: набор собран из текущего растрового логотипа. Для крупной печати рекомендуется дополнительно подготовить true-vector SVG/AI.
